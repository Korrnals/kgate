kgate — opkg feed

Binary package feed for KGATE, the VPN-stack supervisor for Netcraze / Keenetic routers running Entware (sing-box engine + tolerant SOCKS relay + mTLS API).

Package

Packagekgate 1.3.2-1
Architectureaarch64-3.10 (Keenetic/Netcraze Entware)
Ships/opt/sbin/kgate, /opt/sbin/sing-box (pinned 1.11.15), init script, RU-split rulesets, sanitized config templates
Dependsiptables, openssh-server, ca-bundle, curl

Install (Entware on the router)

# SSL-capable fetcher for opkg (once)
opkg install wget-ssl libustream-ssl uclient-fetch

# add the feed
echo "src/gz kgate https://korrnals.github.io/kgate/" >> /opt/etc/opkg.conf

opkg update
opkg install kgate
Notes: avoid opkg install --force-reinstall on this package — reinstall goes through the remove phase and is less tested. Use opkg remove kgate && opkg install kgate instead.
Before any package remove/reinstall, back up your live configs — /opt/etc/kgate/kgate.yaml and /opt/etc/sing-box/config.json — Entware opkg replaces modified conffiles with the shipped templates.

After install

Edit /opt/etc/kgate/kgate.yaml and /opt/etc/sing-box/config.json (templates with placeholder server/password values), then:

/opt/etc/init.d/S99kgate start

The daemon supervises sing-box and the relay, applies ndm configuration (Proxy0 tunnel toggle, route pins, DNS rules) and exposes an mTLS API on :9443.
