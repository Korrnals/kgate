# Администрирование · Веб-панель (`panel`)

Встроенная панель управления kgate прямо в демоне: HTTPS на `:8443`, тот же
процесс (никаких отдельных сервисов). Mobile-first, тёмная тема, на русском;
ставится «карточкой» на домашний экран телефона (PWA-манифест) — это
компенсация невозможности карточки в интерфейсе Keenetic.

## Включение

Панель **выключена по умолчанию** (fail-safe): она поднимается только если в
`kgate.yaml` задан `panel.password`. В логе старта это одна строка
(`panel: выключен (panel.password не задан)` или `panel: HTTPS listener :8443`).

```yaml
panel:
  password: CHANGE_ME              # задан → панель включена
  port: 8443                       # default 8443
  return_url: http://192.168.1.1/  # кнопка «← Приложения»
```

Включение: правишь конфиг → `kgate apply` (деплой рендерит `/opt/etc/kgate/kgate.yaml`
целиком, включая `panel`-секцию) → `/opt/etc/init.d/S99kgate restart`.
Смена пароля — правка `panel.password` + restart (сессии живут в памяти
демона и сбрасываются рестартом).

## Вход и безопасность

- Адрес: `https://192.168.1.1:8443/kgate/`
- **Self-signed предупреждение**: сертификат переиспользован из mTLS API
  (`web_root/server.crt`), центр сертификации локальный — браузер покажет
  предупреждение («Дополнительно → Перейти на сайт»); это ожидаемо.
- Auth: пароль формы → cookie-сессия на 12 часов (HttpOnly, SameSite=Lax).
- Логин задушен: 5 неудачных попыток в минуту с одного IP → 429.
- Мутации (тумблер, смена политики) проверяют `Origin` (CSRF).
- TLS-порт из LAN (Entware) доступен без дополнительных firewall-правил —
  как `:9443`.

## Что умеет (v1)

- **Статус**: sing-box / relay / Proxy0 / режим / uptime / exit-IP
  (exit-IP опрашивается через socks-туннель, кэш 60 с) + **большой тумблер
  VPN** с подтверждением — тот же кодовый путь, что `kgate toggle` (intent +
  Proxy0 + ndm save).
- **Политики**: сегменты — только просмотр; устройства — селект
  VPN / NO-VPN / прямое (unbind = `no ip hotspot host <MAC> policy`,
  prefix-форма) с inline-применением и тостом. Источник истины — живой
  `show ip hotspot` + running-config overlay.
- **Логи**: хвосты `kgate.log` / `singbox.log` (200 строк), автосвеж 5 с на
  активном табе, кнопка «скачать хвост».

## PWA-установка с телефона

1. Открой `https://192.168.1.1:8443/kgate/`, прими self-signed предупреждение,
   войти паролем.
2. Safari (iOS): «Поделиться → На экран “Домой”»; Chrome (Android): меню →
   «Установить приложение».
3. Иконка открывает панель standalone (без адресной строки), тема тёмная.

## Переменные окружения

`KGATE_PANEL_PASSWORD`, `KGATE_PANEL_PORT`, `KGATE_PANEL_RETURN_URL`
(приоритет env > yaml > дефолты, как у остальных `KGATE_*`).
