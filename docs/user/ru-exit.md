# Пользователь · RU-exit (анонимизация)

## Что это

Режим, при котором **весь** трафик дома — включая запросы к локальным сайтам —
уходит через выходной узел туннеля. Сайты видят адрес узла, а не ваш домашний
IP и город: сканеры и сборщики не связывают ваш домашний адрес с активностью.

## Включение и выключение

```bash
kgate ruexit on      # анонимизация включена
kgate ruexit off     # обычный режим (быстрее)
kgate status         # в статусе поле mode: Global = включено, Rule = обычный
```

Тот же переключатель — в веб-дашборде `http://<роутер>:9090/ui/` (Rule/Global).

## Что меняется

| Режим | Локальные сайты видят | Скорость |
|---|---|---|
| Rule (обычный) | ваш домашний IP | максимальная |
| Global (RU-exit) | адрес выходного узла туннеля | латентность +десятки мс, пропускная способность ограничена туннелем |

## Когда включать

- хотите, чтобы сервисы не связывали ваш домашний адрес с активностью;
- на время «чувствительных» сессий; в остальное время — обычный режим быстрее.

## Ограничения

- анонимизируется **исходящий** трафик: это не защита от malware и не инструмент
  для обхода ответственности;
- часть локальных сервисов может показывать капчу (сайт видит «датацентровый» IP);
- полностью «исчезнуть» из сетей невозможно — режим снижает связываемость, а не
  уничтожает её.

## Технические детали

Механика: правило `clash_mode: Global → туннель` в движке + серверное правило
«локальные адресаты → exit с узла». Настройка узла — ответственность
администратора ([ADMIN → RU-exit](../admin/../admin/../architecture/overview.md)).
