# Пользователь · Начало работы

## 🚀 Быстрый старт

Ноутбук оператора — три команды (CLI → конфиг → деплой):

```bash
curl -fsSL https://raw.githubusercontent.com/Korrnals/kgate/main/scripts/install.sh | sh
kgate config create      # конфиг + редактор: host, server_ip, ssh_key
kgate deploy
```

Пошагово — [install.md](../admin/install.md). Пакетный путь на роутер
(opkg-фид) — [alternatives-install.md](../admin/alternatives-install.md);
подготовка роутера — [preparation.md](../admin/preparation.md).

После установки заменить плейсхолдеры (`203.0.113.10`, `hy2.example.com`,
`HY2_PASSWORD`) реальными значениями вашего hysteria2-сервера — туннель
поднимется сам.

## 🎁 Что вы получили

После установки на роутере появился **один переключатель VPN для всего дома**:

| Положение | Что происходит |
|---|---|
| 🟢 **ON** | трафик дома через защищённый туннель; локальные сайты — напрямую |
| 🔴 **OFF** | всё напрямую: локальные сайты работают, часть зарубежных — блокируется провайдером |

Локальные сайты (банки, госуслуги, маркетплейсы) работают в обоих положениях —
их трафик маршрутизируется напрямую всегда.

## 🎛 Два способа управления

1. **Веб-интерфейс роутера** — Интернет → Другие подключения → тумблер **Proxy0**.
2. **Команда с ноутбука**: `kgate toggle on` / `kgate toggle off`.

## ✅ Быстрая проверка

```bash
kgate verify
```

Вывод покажет: процессы стека, состояние туннеля, правила DNS и ваш текущий
выходной IP. Ожидается адрес выходного узла (не домашний), пока тумблер включён.

## 📱 Управление с телефона/планшета

Веб-интерфейс роутера работает с любого устройства в домашней сети — тумблер
доступен без ноутбука.

## 🤖 Что автоматически делает демон

- поднимает стек и туннель после перезагрузки роутера;
- чинит правила DNS, которые роутер периодически сбрасывает;
- перезапускает движок, если тот упал.

Ничего делать руками не требуется: сигналом о проблеме служит `kgate verify`
(см. [FAQ](faq.md)).
