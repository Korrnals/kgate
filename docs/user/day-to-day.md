# Пользователь · Повседневное управление

## ⌨️ Команды

| Команда | Что делает |
|---|---|
| `kgate status` | состояние стека одним экраном |
| `kgate verify` | полная проверка + текущий выходной IP |
| `kgate toggle on` / `off` | включить / выключить VPN для всего дома |
| `kgate logs` | журнал демона |
| `kgate reboot` | перезагрузка роутера |

## 🎛 Тумблер из веб-интерфейса

Интернет → Другие подключения → **Proxy0**. Тот же эффект, что и `kgate toggle`.

## 📊 Дашборд соединений

`http://<роутер>:9090/ui/` — живой список соединений: кто, куда, через какой
канал и сколько трафика. Полезно, чтобы понять, «идёт ли сайт через VPN»:
найдите соединение и посмотрите цепочку (direct = напрямую, hy2 = через туннель).

## 🚫 Разрешённые/запрещённые устройства

Назначаются на роутере: **Приоритеты подключений → Применение политик**.

- устройство без политики — следует тумблеру (ON = через VPN);
- устройство в политике `DIRECT-NOVPN` — всегда напрямую;
- подробности: [ADMIN → Сегменты и политики](../admin/segments-and-policies.md).

## 🔄 Перезагрузка роутера

Стек и туннель поднимаются автоматически. Контроль — `kgate status` через
пару минут после загрузки.
