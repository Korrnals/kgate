# Пользователь · FAQ

> ❓ Частые вопросы пользователей. Диагностика уровня администратора —
> [Admin · Эксплуатация](../admin/operations.md).

## Вопросы

### 🟢 VPN включён — как проверить, что работает?
`kgate verify`: в конце выводится текущий выходной IP. Если он совпадает с
адресом выходного узла (не домашний) — трафик идёт через туннель.

### 🟡 Тумблер включён, а сайты открываются с домашним IP
Устройство находится в сегменте или политике ndm с прямым доступом
(например, IoT-сегмент). Проверка и решение —
[ADMIN → Сегменты](../admin/segments-and-policies.md).

### 🔴 Пропал интернет совсем
1. `kgate toggle off` — вернёт прямой доступ мгновенно.
2. `kgate status` / `kgate logs` — диагностика.
3. После ребута роутера стек поднимается сам; если нет — `kgate toggle off && kgate toggle on`.

### 🟢 Что с телефоном/телевизором?
Они следуют общему тумблеру, если не привязаны к отдельной политике.
Привязки — роутер, «Приоритеты подключений → Применение политик».

### 🟡 Зачем DNS «Яндекс/защищённый»?
Часть доменов провайдеры подавляют на уровне DNS. KGATE направляет DNS-запросы
всех устройств на независимый резолвер — домены резолвятся честно, а трафик
уже идёт по правилам туннеля.

### 🔵 Где смотреть, какой сайт куда идёт
Дашборд: `http://<роутер>:9090/ui/` — соединения, каналы, трафик в реальном времени.
