# API · Тумблер: toggle

> 🔵 Тумблер VPN для всего дома — аналог команды `kgate toggle on|off`
> и переключателя **Proxy0** в веб-интерфейсе роутера.

## 🔎 На этой странице

- 🔵 [POST /api/v1/toggle](#post-apiv1toggle) — включить или выключить туннель

---

## POST /api/v1/toggle

![POST](https://img.shields.io/badge/POST-0969da) `/api/v1/toggle`

### 📖 Описание

Переключает туннельный интерфейс ndm **Proxy0** через `ndmc` — от этого зависит
весь домашний трафик: `on` — через VPN, `off` — напрямую через провайдера.
Демон ждёт смену состояния (~6 с) и возвращает фактический результат.

### 📮 Ответы

| Код | Формат | Описание |
|---|---|---|
| `200` | JSON | интерфейс переключён; ответ приходит после ожидания смены состояния |

### 🧾 Тело запроса

| Поле | Тип | Допустимые значения |
|---|---|---|
| `state` | string | `on` · `off` |

```json
{"state": "on"}
```

### 🧪 Пример запроса

```bash
curl --cacert ~/.kgate/ca.crt --cert ~/.kgate/client.crt --key ~/.kgate/client.key \
     -H 'Content-Type: application/json' \
     -d '{"state":"on"}' \
     https://192.168.1.1:9443/api/v1/toggle
```

### 📥 Пример ответа

```json
{ "ndmc": "interface is up.", "proxy0": "state: up" }
```

| Поле | Значение |
|---|---|
| `ndmc` | вывод команды ndm |
| `proxy0` | фактическое состояние интерфейса после переключения |

### 🚫 Ошибки

| Код | Причина |
|---|---|
| `400` | `state` не `on`/`off` — тело ответа: `state: on|off` (plain text) |
| handshake failure | нет/чужой клиентский сертификат — TLS-уровень, до HTTP |

> [!WARNING]
> `state: off` возвращает весь дом на прямое подключение — часть зарубежных
> ресурсов станет недоступна. Правило смены политики для отдельных сегментов
> — [Admin · Сегменты и политики](../admin/segments-and-policies.md).
