# Архитектура · Обзор

> 🟢 **KGATE** — единая утилита управления VPN-стеком на роутерах Netcraze / Keenetic.
> Один статический Go-бинарь, три роли: **демон-супервизор** на роутере, **mTLS-клиент**
> на ноутбуке, **деплойер** по ssh.

## 🎯 Назначение

KGATE решает задачу «домашний VPN одним переключателем»:

- держит VPN-движок (sing-box) под супервизией: рестарты с бэкоффом, наследуемые
  FD-лимиты, автоподъём после перезагрузок;
- переживает особенности ndm — ОС роутера: пересборки netfilter при любых
  событиях интерфейсов, кривой SOCKS-клиент (BadVPN tun2socks), бут-гонки
  ndm ↔ Entware;
- даёт оператору безопасное управление: mTLS API, детерминированный деплой по ssh,
  идемпотентные стадии;
- даёт пользователю дома простой тумблер: ON — трафик через туннель, OFF — напрямую.

## 🎭 Роли одного бинаря

| Роль | Команда | Окружение | Ответственность |
|---|---|---|---|
| Демон | `kgate serve` | роутер (root, Entware) | супервизор процессов, DNS-правила, socks-relay, авто-подъём туннеля, mTLS API |
| Клиент | `kgate status` и др. | ноутбук оператора/пользователя | тонкая обёртка над mTLS API |
| Деплойер | `kgate deploy` | ноутбук администратора | установка и обновление стека по ssh, миграции legacy |

## 🧭 Принципы дизайна

1. **Детерминизм вместо надежд.** Всё, что демон делает при буте, он делает сам
   и в известном порядке: движок → ожидание порта → подъём туннеля → правила DNS.
2. **Толерантность на границе с ndm.** Роутерная ОС присылает нестандартный
   SOCKS-трафик (verb «command 5») — relay принимает любой verb и транслирует
   его в корректный CONNECT.
3. **Один бинарь — один носитель истины.** Конфиг `kgate.yaml` одинаков на
   ноутбуке и роутере; клиентская и серверная секции изолированы.
4. **Идемпотентность.** Любая стадия `deploy` безопасно повторяется.
5. **Обезличенность артефактов.** Секреты и реальные адреса не хранятся в
   репозитории — только шаблоны `examples/` и локальные оверрайды `local/`.

## 🖥 Поддерживаемые платформы

| Платформа | Статус |
|---|---|
| Netcraze / Keenetic (ndm OS 4.x–5.x, Entware, aarch64) | ✅ целевая, глубокая интеграция |
| Прочие Linux-роутеры | 🟡 задумано: адаптеры платформы (см. [components.md](components.md#-adapters-задел-на-универсальность)) |

## 📦 Состав релиза

- `kgate-<ver>-linux-arm64` — демон/клиент для роутера
- `kgate-<ver>-linux-amd64` — CLI оператора
- `kgate_<ver>-1_aarch64-3.10.ipk` — Entware-пакет (бинарь + init-скрипт + конфиги)
- подписи: `SHA256SUMS` + cosign (Sigstore/Rekor) + GPG detached
